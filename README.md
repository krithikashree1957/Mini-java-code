# Student Menu Application

A simple, interactive console-based Java application designed to manage student details using an object-oriented approach.

---

## 📌 Features

- **Add Student Details**: Input student attributes including Name, Roll Number, Department, and CGPA.
- **Display All Students**: View a formatted list of all stored student records.
- **Interactive Menu**: User-friendly menu loop controlled via console input.

---

## 🛠️ Tech Stack

- **Language:** Java (JDK 8 or higher)
- **Data Structures:** `ArrayList` for dynamic storage of student records

---

## 📁 Project Structure

```text
├── StudentMenuApp.java   # Main Java source code containing Student class and menu driver
└── .vscode/
    └── launch.json       # VS Code launch configuration

```

## 🚀 How to Run

### Prerequisites

Make sure you have Java (JDK) installed on your system. Verify by running:

```bash
java -version

```

### Steps to Execute

1. **Clone or download the repository:**
```bash
git clone [https://github.com/krithikashree1957/Mini-java-code.git](https://github.com/krithikashree1957/Mini-java-code.git)
cd Mini-java-code

```


2. **Compile the Java program:**
```bash
javac StudentMenuApp.java

```


3. **Run the application:**
```bash
java StudentMenuApp

```
